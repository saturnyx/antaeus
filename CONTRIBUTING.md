Before I go on, thank you for taking time to contribute to this project! If
you have any new ideas or code that you want to add to Antaeus I will be more
than happy to help to implement it or accept your pull request. If you are
unsure on whether your pull request will be helpful, you can always find me
in almost all vex servers in discord. Feel free to chat!

Please note that many components of Antaeus have been developed without access
to physical hardware and require thorough testing. If you have access to VEX V5
equipment, we would greatly appreciate your help in testing and validating the
codebase. If you encounter any issues or bugs during testing, please open an
issue on GitHub with details about the problem. Your feedback and contributions
are invaluable to the project's success!
